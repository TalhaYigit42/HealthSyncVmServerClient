# HealthSync — Setup Guide

A full-stack health tracking app built with **Vue 3** (frontend) and **Node.js + Express + PostgreSQL** (backend).

---

## What you need installed

- [Node.js](https://nodejs.org/) v18 or newer
- [PostgreSQL](https://www.postgresql.org/download/) v14 or newer
- Git

---

## Step 1 — Clone the repo

```bash
git clone https://github.com/TalhaYigit42/HealthSyncVmServerClient.git
cd HealthSyncVmServerClient
```

---

## Step 2 — Set up PostgreSQL

### Create the database and user

Open a terminal and run:

```bash
sudo -u postgres psql
```

Then inside psql, paste this:

```sql
CREATE USER healthsync_user WITH PASSWORD 'Bartal123!';
CREATE DATABASE healthsync OWNER healthsync_user;
GRANT ALL PRIVILEGES ON DATABASE healthsync TO healthsync_user;
\q
```

### Import the database schema and data

```bash
psql -U healthsync_user -d healthsync -f healthsync_dump.sql
```

If it asks for a password, enter: `Bartal123!`

---

## Step 3 — Configure the backend

Create a `.env` file in the root folder:

```bash
cp .env.example .env 2>/dev/null || touch .env
```

Open `.env` and paste this (edit values if you changed the DB password):

```
PORT=3000
JWT_SECRET=HealthSync_S3cur3_JWT_S3cr3t_K3y_2025!

DB_HOST=localhost
DB_USER=healthsync_user
DB_PASSWORD=Bartal123!
DB_NAME=healthsync
DB_PORT=5432

EMAIL_USER=
EMAIL_PASS=
APP_URL=http://localhost:3000
```

> `EMAIL_USER` and `EMAIL_PASS` are only needed for password reset emails. Leave them blank if you don't need that.

---

## Step 4 — Install backend dependencies

```bash
npm install
```

---

## Step 5 — Build the frontend

```bash
cd frontend
npm install
npm run build
cd ..
```

This compiles the Vue app into `frontend/dist/`, which the backend serves automatically.

---

## Step 6 — Start the app

```bash
node server.js
```

Then open your browser and go to:

```
http://localhost:3000
```

You should see the HealthSync login page. Register a new account and you're in.

---

## Troubleshooting

**"password authentication failed for user healthsync_user"**
- Make sure PostgreSQL is running: `sudo systemctl start postgresql`
- Double-check the password in `.env` matches what you set in Step 2

**"relation does not exist" errors**
- The database import didn't run properly. Re-run Step 2's import command.

**Port 3000 already in use**
- Change `PORT=3000` in `.env` to another port like `3001`, then visit `http://localhost:3001`

**Frontend shows a blank page**
- Make sure you ran `npm run build` inside the `frontend/` folder (Step 5)

│   │   ├── views/         # Pages (Dashboard, Health, Sleep, etc.)
│   │   ├── components/    # Reusable UI components
│   │   └── router.js      # Page routing
│   └── dist/              # Built frontend (generated by npm run build)
